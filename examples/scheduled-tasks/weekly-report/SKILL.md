워크스페이스 전체의 자동 주간보고 루틴 예시. 매주 금요일 그 주(월~금)를 정리. 모든 출력은 한국어, 사실 기반·간결. **코드 수정 금지(읽기·분석만).**

## 경로/프로젝트 정의

`daily-report`와 동일: cwd 기반 워크스페이스 루트 자동 탐지, 프로젝트 = 직하위 `CLAUDE.md` 보유 폴더.

## 절차

### 1) 취합
- 저장 루트 `<워크스페이스 루트>/<일일보고 폴더>/<N월>/<N주차>/` 에서 이번 주 월~금 일일보고(YYYY-MM-DD.md)를 모두 읽음.
- 한 파일에 여러 프로젝트 섹션이 있으면 **프로젝트별로 모두 취합**.
- **일일보고 내용만 근거로 사용** — git log·mtime을 다시 훑어 메타 작업(보고/메모리/설정)을 끌어오지 않음. 일일보고가 주간보고의 진실 소스.
- 작성 일수·누락 요일 집계.

### 2) 작성
- 정해진 6개 섹션 골격(예: 요약 / 프로젝트별 진척 / 이슈 / 다음 주 계획 …)을 따라 작성.

### 3) (선택) 외부 산출물 기입
- 노션/구글시트 등 보고 채널이 있으면 동일 명칭·용어·수치·주차로 기입.
- **일체감 규약**: 로컬·노션·시트가 같은 프로젝트 표시명/주차 표기/상태 어휘를 쓰도록 통일.
- 시트 자동 기입은 검증된 스크립트로, 기입 후 재읽기 검증. 행 추가/삭제·표 구조 변경은 지양.

> 외부 산출물 생성·갱신 트리거는 사용자 정책/확인에 따름.
