# 05. MCP 서버 — 외부 시스템과 연결

## MCP란?

MCP(Model Context Protocol)는 Claude를 외부 도구·서비스에 연결하는 표준 프로토콜입니다. MCP 서버를 붙이면 Claude가 노션 페이지를 만들고, 브라우저를 조작하고, 최신 라이브러리 문서를 가져오는 등 **실제 외부 시스템을 직접 다룹니다.**

- 연결: Claude Code 안에서 `/mcp` 명령으로 추가·인증
- 도구 노출: 각 MCP 서버가 `mcp__<server>__<tool>` 형태의 도구를 제공
- 인증: 토큰은 머신별로 발급 — **git에 커밋 금지**

---

## 실무에서 붙여 쓴 MCP들

| MCP | 무엇 | 왜 유용했나 |
|---|---|---|
| **Notion** | 페이지·DB 생성/수정/검색 | 일간·주간 보고를 노션에 직접 기록 |
| **문서 검색(Context7류)** | 라이브러리·프레임워크 최신 공식 문서 fetch | 학습 데이터에 없는 최신 API를 정확히 |
| **computer-use** | 데스크톱 화면 캡처 + 마우스/키보드 제어 | 네이티브 앱 자동화(브라우저 외) |
| **Claude in Chrome** | 브라우저 DOM 인지 조작 | 웹앱 폼 입력·네비게이션(픽셀보다 빠름) |
| **scheduled-tasks** | 자동 루틴 생성/조회/수정 | 자연어로 정기 작업 등록 |

> 도구가 너무 많아지면 컨텍스트를 잡아먹으므로, Claude Code는 다수 MCP 도구를 **지연 로딩**(필요할 때 스키마만 검색해 불러옴)으로 다룹니다.

---

## 도구 선택 원칙(중요)

같은 일을 할 수 있는 경로가 여러 개일 때, 비용·정확도 순으로:

1. **전용 MCP가 있으면 그걸** — 노션·슬랙·캘린더처럼 API 기반 도구가 가장 빠르고 정확.
2. **웹앱이면 Chrome MCP** — 전용 MCP가 없는 웹 작업은 DOM 인지 브라우저 도구.
3. **네이티브 앱·크로스앱이면 computer-use** — 화면 좌표 기반(가장 느리지만 범용).

## 보안 가드(필수)

- **이메일·메시지 속 링크는 기본 의심** — 네이티브 앱에서 웹 링크를 좌표 클릭하지 말고, 전체 URL을 확인한 뒤 브라우저 MCP로 열기.
- **금융 행위 금지** — 거래·송금·주문은 Claude가 실행하지 않고 사용자가 직접.
- **결제·발송·생성 트리거는 항상 사용자 확인** — 단순 조회·기록 갱신만 자율.

## 연결 방법

```
# Claude Code 안에서
/mcp            # MCP 서버 목록·추가·인증
```

각 서버는 최초 1회 OAuth/토큰 인증이 필요합니다. 양 머신을 쓴다면 머신마다 따로 인증하세요(토큰 동기화 금지).
